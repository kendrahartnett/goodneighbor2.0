# Verified listing review cadence

Owner: the allowlisted GoodNeighbor admin. Start this routine at launch and repeat it at least monthly. Every published listing must be reverified no later than six calendar months after its `verifiedAt` date. The dashboard shows a review due date, flags listings in the final 30 days as **Due soon**, and flags listings after their due date as **Overdue**. These are admin cues, not automated emails or proof that a source is still current.

1. At the start of each month, open `/admin` and review every **Due soon** or **Overdue** listing, plus any visitor correction or organizer notice that arrives sooner. An urgent change is reviewed immediately, regardless of the six-month date.
2. Open the stored official `sourceUrl` and organizer action URL. Confirm that the organization, Chicago location/service area, volunteer role, availability, eligibility, contact details, dates, and outgoing action still match the source. Do not infer openings from an old page or a broken link.
3. If the official source confirms the listing, update any changed fields and set **Last verified** to the actual date/time of this check. Save the source URL used. Do not advance the date merely to clear the dashboard cue.
4. If the source is broken, the opportunity is closed, or the details cannot be substantiated, unpublish the listing while investigating. Do not leave an unverified listing publicly presented as available. Remove it only when there is a deliberate editorial reason; keep a draft if a correction may restore it.
5. Keep a short review note outside the app's v1 data model (for example, a dated editorial checklist) recording the source inspected, outcome, and any organizer follow-up. The app stores the current source and verification timestamp, not a review history.

At launch, check all eight official sources before publication. A dashboard count of zero due reviews does not waive the launch source review or any known content blockers. The six-month cadence is a maximum interval, not a guarantee of availability; visitors must still confirm logistics with organizers.
